# Basic Blog Post Layout

## 📌 Project Description
This project is a simple and responsive blog post layout created using HTML and CSS. It demonstrates the basic structure of a blog page, including a header, blog title, author information, publication date, main content, and footer.

## 🎯 Objectives
- Create a basic blog post layout using HTML.
- Style the page using CSS.
- Organize blog content in a clean and readable format.
- Make the layout responsive for different screen sizes.

## 🛠️ Technologies Used
- **HTML5** – For the structure of the webpage.
- **CSS3** – For styling and layout.

## 📂 Project Structure
```text
basic-blog-layout/
├── index.html
├── style.css
└── README.md
```

## 🚀 How to Run the Project
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. View the blog post layout.

## ✨ Features
- Simple and clean blog design.
- Blog title and author details.
- Readable article content.
- Styled header and footer.
- Responsive layout for mobile and desktop screens.

## 📚 Learning Outcomes
- Understanding basic HTML page structure.
- Applying CSS styling and spacing.
- Using semantic HTML elements.
- Organizing files in a web development project.
